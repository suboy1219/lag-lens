## Description

Your PC freezes. By the time Task Manager opens, everything looks normal again.

LagLens is a small Windows tray tool that samples every second and keeps the last 60 seconds in memory. After a freeze, open it and see:

- A one-line verdict: disk, CPU, or memory
- The last 60 seconds of CPU and disk history — pause and step frame by frame
- The top 5 apps grouped by process — click any row to locate the program in Explorer

No pop-ups. No network. No uploads. Portable, for Windows 10 / 11 x64.

GitHub: https://github.com/suboy1219/lag-lens

Demo data is simulated. Built with LagLens v1.0.4.

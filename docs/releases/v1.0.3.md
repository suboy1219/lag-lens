## 卡顿侦探 · LagLens v1.0.3

### 本次更新
- 新增键盘 `←` / `→` 逐帧回看：切换上一帧 / 下一帧，指标和 Top5 应用列表同步更新。
- 实时状态下按方向键，从鼠标预览的帧开始；没有预览时从最新帧开始，并暂停时间轴。
- 到最早 / 最新帧时停止，不循环；暂停后仍可点击曲线选择其他帧，按 `Esc` 或点击「恢复实时」继续。
- 暂停期间保留时间轴副本，新采样不会挤走选中帧。
- 完善 README 操作说明，补充 IOPS 的含义、显示条件及统计范围。

### 下载与使用
下载 `LagLens-v1.0.3-win-x64.zip`，解压后运行 `LagLens.exe`。更新前请先从托盘右键菜单退出旧版本，再替换程序。

支持 Windows 10 / 11 x64，已包含 .NET 运行时，无需单独安装。

### 说明
- 程序常驻托盘，左键单击托盘图标打开 / 关闭面板。
- 如需排查采样问题，可运行 `LagLens.exe --probe`，采样结果写入 `%TEMP%\laglens-probe.txt`。
- 下载后可使用附件 `SHA256SUMS.txt` 校验压缩包的完整性。

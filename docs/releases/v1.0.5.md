## 卡顿侦探 · LagLens v1.0.5

### 本次更新

- 托盘图标由“圆环加圆点”改为实心闪电，与护眼卫士的圆环图标更容易区分。
- 保留绿、橙、红三种负载状态颜色，在小尺寸托盘中也能辨认。

### 下载与使用

下载 `LagLens-v1.0.5-win-x64.zip`，解压后运行 `LagLens.exe`。更新前请先从托盘右键菜单退出旧版本，再替换程序。

支持 Windows 10 / 11 x64，已包含 .NET 运行时，无需单独安装。现有卡顿记录保留。

附件 `SHA256SUMS.txt` 提供下载压缩包的 SHA-256 校验值。

### English

- Replaced the ring-and-dot tray icon with a solid lightning bolt to distinguish LagLens from EyeGuard.
- Kept the green, orange, and red load indicators, with a recognizable silhouette at small tray sizes.

Download `LagLens-v1.0.5-win-x64.zip`, extract it, and run `LagLens.exe`. Exit the previous version from its tray menu before replacing the application files. Existing incident records are preserved.

Supports Windows 10 / 11 x64. The .NET runtime is included. Use `SHA256SUMS.txt` to verify the downloaded archive.
